# Dark OS - Browser Extension

A customizable and **privacy-friendly dark mode extension** with advanced filters and themes for a comfortable browsing experience. Dark OS runs entirely **locally on your browser**, so your browsing data stays private and secure.

## Features

* 🌙 **Multiple Dark Themes**

  * Invert Mode
  * Dynamic Mode
  * Reading Mode
* 🎨 **Color Filters**

  * Brightness
  * Contrast
  * Grayscale
  * Blue Light Filter
* ⚙️ **Website-Specific Settings**

  * Customize dark mode behavior for individual websites
* 📅 **Scheduling Support**

  * Automatically switch themes based on time of day
* 💡 **Reading Mode**

  * Warm tones for comfortable reading

## Safety & Privacy

* Runs **entirely locally**, no data is sent to any server.
* **Open source**: you can inspect all code to ensure it’s safe.
* No tracking, ads, or unwanted permissions.

## Installation

1. Download or clone this repository.

   ```bash
   git clone https://github.com/hamethius/Dark-OS.git
   ```
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (toggle in the top right corner).
4. Click **Load unpacked** and select the extension folder.

## Usage

* Click the **Dark OS** icon in your browser toolbar to open the settings panel.
* Select your preferred theme and color filters.
* Enable **website-specific settings** to customize dark mode for individual sites.
* Use the **scheduler** to automate theme changes based on time.
